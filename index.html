في Firebase Console: أنشئ Firestore Database بوضع Native، ثم Rules والصق القواعد التالية واضغط Publish: 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} { allow read, write: if true; }
  }
}
القواعد مفتوحة وتناسب التجربة. بعد التحويل للسحابي استورد ملف الإكسل مرة أخرى.
